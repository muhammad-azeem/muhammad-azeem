# Hospitality Uniforms & Embroidery — WordPress Demo

Complete WordPress implementation based on the supplied hospitality uniforms brief.

Included:
- Premium navy and gold responsive theme
- Home, Services, Hospitality Solutions, About and Get a Quote pages
- Secure quote form with garment selection and logo upload
- Quote requests stored in WordPress admin
- Owner email notification using WordPress mail
- Business details editable through Appearance > Customize
- Basic SEO meta descriptions
- Mobile navigation and responsive layout
- Elementor installed in the live Playground preview
