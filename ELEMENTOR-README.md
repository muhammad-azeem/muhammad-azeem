# Hospitality Uniforms — Elementor Final

This branch contains the Elementor-first delivery version.

## What is editable in Elementor
- Home
- Services
- Hospitality Solutions
- About
- Get a Quote page layout
- Header template
- Footer template
- Headings, text, buttons, images, cards, spacing and section structure

## Functional layer
The quote form is inserted into the Elementor page using a Shortcode widget. The form itself is powered by the separate Hospitality Quote Manager plugin so it can securely save requests, upload logos, and send owner email notifications.

## Client brief coverage
- Deep Navy #0A2540 + Gold #C9A227
- Professional hospitality-uniform imagery
- Fully responsive design
- Home CTA and required benefits
- Services: Custom Embroidery, Logo Digitization, Branded Hospitality Apparel, Easy Reordering
- Products: Chef coats, server shirts/blouses, aprons, kitchen/front-of-house uniforms, caps/hats, suitable outerwear
- Role-based Hospitality Solutions
- Established/professional About copy
- Highest-priority Get a Quote page
- Logo upload and quote email workflow
- Basic SEO and optional Google Analytics setting

## Editing
Pages: WordPress Dashboard → Pages → Edit with Elementor.
Header/footer: WordPress Dashboard → Templates → Saved Templates → edit “Site Header - Elementor Editable” or “Site Footer - Elementor Editable”.

The final client business name, logo, phone, email, service area, domain and hosting are not present in the supplied brief and must be replaced once the client provides them.
